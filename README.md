# Planejador de Rotas

## Status do projeto
Projeto em desenvolvimento.

## Tecnologias utilizadas
- Java
- Java Swing
- MySQL
- JDBC
- GitHub

## Desenvolvedor
Murilo Costa

## Objetivo do software
O sistema Planejador de Rotas foi desenvolvido para auxiliar no gerenciamento de rotas, docas e importações logísticas.

## Funcionalidades do sistema
- Cadastro de rotas
- Cadastro de docas
- Cadastro de importações
- Integração com banco de dados MySQL
- Interface gráfica desktop
